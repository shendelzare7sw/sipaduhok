SIPADUHOK UI Kit

Rekonstruksi seluruh antarmuka aplikasi sebagai HTML statis, untuk di-import menjadi layer Figma. Nilai desainnya diambil dari CSS produksi, bukan dikarang.

Untuk apa berkas ini

Aplikasi SIPADUHOK sudah selesai dibangun, tetapi artefak prototype Figma-nya hilang. UI kit ini adalah jalan pintas untuk merekonstruksinya: buka berkasnya di browser, lalu import dengan plugin html.to.design — hasilnya layer Figma asli (frame, teks, warna yang bisa diedit), bukan tangkapan gambar.

Yang perlu direkonstruksi adalah 57 layar setelah login untuk 9 peran pengguna. Desain halaman publik sudah dibuat sebelumnya dan sudah ada di workspace Figma — berkas screens/01-publik.html disertakan hanya sebagai pembanding, lewati saat import. Semua penamaan frame mengikuti docs/figma/03-inventaris-layar.md.

Penting saat import. Shell (sidebar + navbar) dirakit oleh JavaScript agar 11 varian sidebar tidak perlu disalin ulang di puluhan berkas. Karena itu import harus memakai mode ekstensi browser html.to.design yang membaca DOM setelah halaman ter-render — bukan mode “import from URL”. Untuk berkas lokal (file://), mode ekstensi memang satu-satunya pilihan.
