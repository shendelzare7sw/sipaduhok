# Clean Code Refactor Views

Catatan ini dipakai sebagai checkpoint agar refactor views after-login berjalan bertahap, mudah diaudit, dan tidak menyentuh ulang halaman yang sudah stabil tanpa alasan.

## Prinsip

- Halaman kecil/menengah memakai pola satu Blade, satu CSS, dan satu JS scoped per halaman.
- Partials dipakai selektif untuk halaman besar, blok berulang, tabel ringkasan, stats cards, atau modal yang membuat Blade utama terlalu panjang.
- CSS dan JS global tidak dipakai untuk perubahan baru kecuali memang sudah menjadi pola layout yang ada.
- Halaman public/landing sebelum login tidak disentuh.
- `resources/views/admin/google-sheets` diabaikan karena menu sudah dinonaktifkan.
- Halaman cetak/preview rapor diperlakukan sebagai area sensitif. Jika tampilan cetaknya sudah stabil, cleanup inline style pada file tersebut boleh dilewati agar tidak merusak format print/PDF.
- Setiap batch wajib melewati minimal `php artisan view:cache`, `npm run build`, dan scan inline CSS/JS pada file yang disentuh.

## Validasi Terakhir

- `php artisan view:cache`
- `npm run build`
- `git diff --check`
- Scan Wali Kelas tidak menemukan blok `<style>` atau `<script>` internal pada folder `jadwal`, `nilai`, `presensi`, dan `rapor`.
- Scan Wali Kelas tidak menemukan inline event handler (`onclick`, `onchange`, dll.) atau JavaScript URL.
- Scan Wali Kelas tidak menemukan inline `style=""` pada halaman web biasa di luar print/preview.
- Scan asset Wali Kelas tidak menemukan token Blade/PHP (`{{`, `@json`, `route(`, `asset(`) di CSS/JS hasil pemisahan.
- Scan runtime tidak menemukan referensi `shared.*`, `keuangan-shared`, atau `resources/*/shared`.

Catatan: warning CRLF dan warning konfigurasi Tailwind/Browserslist masih muncul, tetapi bukan error hasil refactor view.

- Lanjut audit inline style/script di view role non-admin yang belum disentuh penuh, terutama LMS/forum dan menu operasional role lain.
